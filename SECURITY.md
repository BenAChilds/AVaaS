# Security policy

Security reports must not be filed as public issues. Email the repository maintainer using the private contact in the GitHub profile or use GitHub's private vulnerability reporting feature. Include affected versions, impact, reproduction details, and suggested remediation without real credentials or malware.

Only the latest released minor version receives security fixes. We aim to acknowledge reports within three business days and coordinate disclosure after a fix is available. Never test against infrastructure you do not own or have permission to assess.
